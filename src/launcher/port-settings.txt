# The port settings: every setting of port-settings.toml, in the file's order. Three parts read this table: the hooks'
# loader (src/hooks/loader/), which sets each setting the file changes as the environment variable that KSA Metal, its
# shims and its hooks read, when the game starts; scripts/make-port-settings.sh, which writes the file's commented
# template from it; and the Mac Port tab in the game's settings (src/hooks/), which draws its rows from it. A variable
# already set when the game starts wins over the file.
#
# [<section>] <title> | <caption>: starts a section of the file and of the tab, the caption being the line under its
# title (and the file's comment); [developer]'s settings are in the file only. Then one setting per line; a choice can
# be followed by indented lines "<value> | <help>", what its values mean (the dropdown's tooltips):
#
#   key | type | default | variable | needs | applies | hook | label | help
#
#   type      bool: on or off; available: Available or Off, a feature the Mac offers the game, which the game's own
#             settings still turn on and off; choice:<value>=<label>/...; scale:<min>:<max>, a fraction shown in
#             percent; int:<min>:<max>; number:<min>:<max>; numbers:<min>:<max>, that many numbers, comma separated,
#             or none; text
#   default   the value a line left out takes, and the one the variable means when it isn't set or holds none of the
#             setting's values
#   variable  what the setting sets when it isn't at its default: on is 1 and off 0 (VAR=<value>: that, for on), other
#             types their value. Without one, the setting is the tab's own
#   needs     the settings it depends on (comma separated): <key> (on, or not empty), <key>=<value>, <key>!=<value>,
#             game:vsync, game:plume_trail_shadows or game:pcss (the game's own settings, which only the tab checks).
#             While one isn't met, it keeps its default
#   applies   live: on Apply, in the running game (the hooks read it while the game runs); restart: when the game
#             starts
#   hook      the hook that does it (src/hooks/Hooks.cs): the tab shows the setting as unavailable when the hook was
#             skipped or failed
#   label     its row in the tab; help: the row's tooltip and the file's comment, which the values' help follows

[image] Image | MetalFX draws the 3D view at another size and scales it to the display.
upscaling | choice:off=Off/metalfx=MetalFX Temporal/spatial=MetalFX Spatial | off | KSA_UPSCALER | | restart | | Upscaling | Draws the 3D view at the Render Scale below and scales it up to the display with Apple's MetalFX.
    off | The game's own. The 3D view is drawn at the window's size.
    metalfx | Builds each image from the ones before it: the sharpest, even at a low Render Scale, and it smooths edges itself. Things that move fast can look a little soft.
    spatial | Scales each image on its own: nothing trails behind in motion, but the image is softer below 100 %. The game's Anti-Aliasing (Display) applies.
render_scale | scale:0.5:2 | 1.0 | KSA_RENDER_SCALE | upscaling!=off | restart | render_scale | Render Scale | The size the 3D view is drawn at, as a share of the window's, before MetalFX scales it up. Lower is faster and a little softer. Above 100 %, up to 200 % on a Retina display, is sharper and much more work for the GPU.
override_antialiasing | bool | true | KSA_OVERRIDE_AA | upscaling=metalfx | restart | render_scale | Skip Game Anti-Aliasing | While MetalFX is on, the game's Anti-Aliasing (Display) is turned off: MetalFX smooths edges itself, so the game's would only cost frame rate and leave dark specks on the planet. Off: the game's setting applies, except CMAA2, which stays off because it can't work with MetalFX.

[interface] Interface | How the flight HUD fits this display.
hud_layout | choice:fit=Fit to Display/game=Scale with Window | fit | KSA_HUD_LAYOUT | | live | hud_layout | HUD Layout | How the flight HUD is sized.
    fit | The same size in a window as in fullscreen, smaller on a display narrower than 16:9 such as a MacBook's, and the panels' text scaled to fit them. If panels overlap in a small window, lower HUD Scale (Interface).
    game | The game's own. Sized from the window, with the panels' text at one size, which overflows them in smaller windows.

[performance] Extra Performance | Faster, with a small change to the image. The default is the game's own.
cloud_shadow_tuning | choice:off=Normal/slower_refresh=Slower | off | KSA_CLOUD_SHADOW_TUNING | | restart | cloud_shadow_tuning | Cloud Shadow Updates | How often the shadows that clouds cast on the ground are updated.
    off | The game's own.
    slower_refresh | About 4 times less often: a little faster over Earth, and the shadows lag behind moving clouds.
plume_shadow_tuning | choice:off=High/low=Low | off | KSA_PLUME_SHADOW_TUNING | game:plume_trail_shadows | restart | plume_shadow_tuning | Plume Shadow Quality | The shadows that rocket smoke casts from the sun, with the game's Plume trail shadows (Graphics).
    off | The game's own.
    low | Less detail, and only within 3 km: the smoke of a big rocket draws about 10-20 % faster, and its shadows on the ground are coarser.
shadow_search | bool | false | KSA_SHADOW_SEARCH | game:pcss | restart | shadow_search | Simpler PCSS Shadows | With the game's Cascaded Shadow Filter on Pcss (Graphics), soft shadows close to the camera look a shorter way for what casts them: about 9 % faster in grass. A shadow cast from high above can get a sharper edge. Off is the game's own.
milky_way_bake | bool | false | KSA_MILKY_WAY_BAKE | | restart | milky_way_bake | Baked Milky Way | The Milky Way's dust clouds are drawn from a picture made once when the game starts: faster with much sky in view, and Milky Way Quality (Graphics) up to High costs no more than Low. Their finest grain is softer. Off is the game's own.

[optimizations] Optimizations | The same image, faster. Leave them on; turn one off to find a problem.
terrain_cache | bool | true | KSA_TERRAIN_CACHE | | restart | terrain_cache | Terrain Cache | The terrain's shape and shading are worked out again only when something about them changed, instead of every frame: a higher frame rate, the same image. Off: try it when terrain looks wrong.
outline_skip | bool | true | KSA_OUTLINE_SKIP | | restart | outline_skip | Skip Unused Outlines | The outline around selected parts is drawn only while a part is selected: a higher frame rate, the same image. Off: try it when a selected part has no outline.
overlay_skip | bool | true | KSA_OVERLAY_SKIP | | restart | overlay_skip | Skip Unused Overlays | The steps that draw gizmos and orbit lines over the 3D view run only on frames that have some: a higher frame rate, the same image. Off: try it when a gizmo or an orbit line is missing.
hidden_parts_skip | bool | true | KSA_HIDDEN_PARTS_SKIP | | restart | hidden_parts_skip | Skip Hidden Vessel Parts | Parts of a vessel hidden behind something else are no longer shaded: a higher frame rate, most in the cockpit, the same image. Off: try it when a vessel looks wrong.
ocean_blending | bool | true | KSA_OCEAN_BLENDING | | restart | ocean_blending | Skip Unused Ocean Blending | Near the ocean's surface (below 9 km), the ocean is drawn without a step only views from higher up need: a higher frame rate, the same image. Off: try it when the ocean looks wrong.
crew_portraits | choice:always=Every Frame/shown=When Shown/shown_15=Shown, 15 FPS | shown | KSA_CREW_PORTRAITS | | live | crew_portraits | Crew Portraits | The crew panel's portraits are small views the game draws every frame while the vessel has crew, even with the panel closed.
    always | The game's own.
    shown | Drawn only while the crew panel is open: the same image.
    shown_15 | Drawn only while the crew panel is open, and at most 15 times a second: the faces move less smoothly.
worker_parking | bool | true | KSA_WORKER_PARKING | | restart | worker_park | Idle Thread Sleep | The game's background threads sleep while they wait for work instead of keeping the CPU busy: the same frames, about a core and a half less CPU time. Off: try it when the game stutters.
loading_pace | bool | true | KSA_LOADING_PACE | | restart | loading_pace | Loading Screen FPS Cap | While the game loads, its loading screen is drawn at most 30 times a second instead of after every step: the game loads about 2 seconds faster. Off: try it when the loading screen looks stuck.
fused_tessellation | bool | true | KSA_MTL_TESS_FUSE | tessellation | restart | | Fused Tessellation | Terrain and ocean are tessellated in one combined step, without a round trip through memory: a higher frame rate over terrain, the same image. Off: try it when terrain or ocean look wrong.
vsync_pacing | bool | true | KSA_MTL_PRESENT_PACING | game:vsync | restart | | Vsync Pacing | With Vsync, a frame starts as soon as the GPU is ready for it, not only once the display has shown the one before: a higher frame rate in a window. Off: try it when the frame rate is uneven with Vsync.
background_compiling | bool | true | KSA_MTL_ASYNC_PIPELINES | | restart | | Background Shader Compiling | Shaders are compiled in the background, so the game doesn't stop for each one. Off: the game waits for each one; try it when something appears late or not at all.
shader_cache | bool | true | KSA_MTL_CACHE | | restart | | Shader Cache | Translated shaders are kept on disk, in ~/Library/Caches/ksa-metal, so later starts don't translate them again. Off: every start translates them; try it when something is drawn wrong.
texture_mapping | bool | true | KSA_KTX_SHIM | | restart | | Texture File Mapping | Textures' pixels are read from files instead of held in memory of their own, so macOS can let go of them when memory runs short and read them back later: about 3 GB less memory with the solar system. Off: try it when a texture looks wrong.
constant_memory | bool | true | KSA_MTL_AB_CONSTANT | | restart | | Shader Constant Memory | Shaders read the textures and data they draw with through a faster kind of memory: a little faster, the same image. Off: try it when something is missing or drawn wrong.
uniform_references | bool | true | KSA_MTL_UNIFORM_REFS | | restart | | In-Place Shader Parameters | Shaders read the game's parameters where they are instead of copying them over and over: the smoke of a big explosion draws about 7-9 % faster, with the same image. Off: try it when something looks wrong.
uncompressed_textures | bool | true | KSA_MTL_UNCOMPRESSED_TEXTURES | | restart | | Skip GPU Texture Compression | Textures such as terrain heights, cloud noise and the sea's waves skip the GPU's own compression, which slows how shaders read them: terrain draws about 2-4 % faster, over clouds and the sea up to 10 %, with the same image and memory. Off: try it when something looks wrong.
ray_hits | bool | true | KSA_MTL_RT_INTERSECTOR | ray_tracing | restart | | IVA Ray Search | With IVA Ray Tracing (Graphics) on, the cockpit's rays find what they hit through a faster kind of ray search: the cockpit draws about 6 % faster, with the same image. Off: try it when the cockpit looks wrong.
unlit_shadow_skip | bool | true | KSA_MTL_UNLIT_SHADOW_SKIP | | restart | | Skip Shadows on Unlit Sides | Shadows are worked out only where light reaches (terrain, vessels and kittens facing the light, sunlit grass and buildings, the sunlit sea, godrays, the cockpit's ray tracing): the cockpit draws about 45 % faster, grass at night about 8-16 %, with the same image. Off: try it when a shadow looks wrong.
