# The port settings: every setting of port-settings.toml, in the file's order. Three parts read this table: the hooks'
# loader (src/hooks/loader/), which sets each setting the file changes as the environment variable that KSA Metal, its
# shims and its hooks read, when the game starts; scripts/make-port-settings.sh, which writes the file's commented
# template from it; and the Mac Port tab in the game's settings (src/hooks/), which draws its rows from it. A variable
# already set when the game starts wins over the file.
#
# [<section>] <title>: starts a section of the file and of the tab; [developer]'s settings are in the file only.
# Then one setting per line:
#
#   key | type | default | variable | needs | applies | hook | label | help
#
#   type      bool: on or off; available: Available or Off, a feature the Mac offers the game, which the game's own
#             settings still turn on and off; choice:<value>=<label>/...; scale:<min>:<max>, a fraction shown in
#             percent; int:<min>:<max>; number:<min>:<max>; text
#   default   the value a line left out takes, and the one the variable means when it isn't set
#   variable  what the setting sets when it isn't at its default: on is 1 and off 0 (VAR=<value>: that, for on), other
#             types their value. Without one, the setting is the tab's own
#   needs     the settings it depends on (comma separated): <key> (on, or not empty), <key>=<value>, <key>!=<value>,
#             game:vsync or game:plume_trail_shadows (the game's own settings, which only the tab checks). While one
#             isn't met, it keeps its default
#   applies   live: on Apply, in the running game; restart: when the game starts
#   hook      the hook that does it (src/hooks/): the tab shows the setting as unavailable when the hook was skipped
#   label     its row in the tab; help: the row's tooltip and the file's comment

[image] Image
upscaling | choice:off=Off/metalfx=MetalFX/spatial=MetalFX spatial | off | KSA_UPSCALER | | restart | | Upscaling | Apple's MetalFX draws the 3D view at the render scale below and scales it up to the display. MetalFX builds each image from the previous ones too: the sharpest, even at a low render scale, and it smooths edges itself; things that move fast can look a little soft. MetalFX spatial scales each image on its own: nothing trails behind in motion, but the image is softer below 100 %, and the game's anti-aliasing stays on. Off is the game's own, without the settings below.
render_scale | scale:0.5:2 | 1.0 | KSA_RENDER_SCALE | upscaling!=off | restart | render_scale | Render scale | The 3D view is drawn at this share of the window's size and MetalFX scales it up to the display. Below 100 %: less work for the GPU, a slightly softer image. Above 100 %, up to the display's full resolution (200 % on a Retina display): a sharper image, much more work for the GPU.
override_antialiasing | bool | true | KSA_OVERRIDE_AA | upscaling=metalfx | restart | render_scale | Override anti-aliasing | Turns off the game's own Anti-aliasing setting (Graphics) while MetalFX is on: MetalFX smooths edges itself, so the game's anti-aliasing only costs frame rate and leaves dark specks on the planet. Off: the game's setting applies, except CMAA2, which stays off with either kind of MetalFX because it can't work with it.

[interface] Interface
hud_layout | choice:fit=Fit to the display/game=The game's | fit | KSA_HUD_LAYOUT | | live | hud_layout | HUD layout | The flight HUD sized for the display. Fit to the display gives it the same size in a window as in fullscreen, shrinks it on a display narrower than 16:9, such as a MacBook's, so its panels don't overlap, and scales the text in the resources, staging and crew panels with the panels, so it fits; in a small window the panels can overlap, which a lower HUD Scale (Interface) fixes. The game's own sizes the HUD from the window and keeps that text at one size, which overflows its panels in smaller windows.

[performance] Performance
cloud_shadow_tuning | choice:off=Off/slower_refresh=Slower refresh | off | KSA_CLOUD_SHADOW_TUNING | | restart | cloud_shadow_tuning | Cloud shadow tuning | Slower refresh updates the shadows the clouds cast about 4 times less often: a little faster over Earth, and the shadows lag behind moving clouds. Off is the game's own.
plume_shadow_tuning | choice:off=Off/low=Low | off | KSA_PLUME_SHADOW_TUNING | game:plume_trail_shadows | restart | plume_shadow_tuning | Plume shadow tuning | With the game's Plume trail shadows, rocket smoke casts shadows from the sun. Low draws them with less detail and only within 3 km: the smoke of a big rocket draws about 10-20 % faster, and its shadows on the ground are coarser. Off is the game's own.
[optimizations] Optimizations
terrain_cache | bool | true | KSA_TERRAIN_CACHE | | restart | terrain_cache | Terrain cache | The terrain's shape and shading are worked out again only when something about them changed, instead of every frame: a higher frame rate, the same image. Off: try it when terrain looks wrong.
outline_skip | bool | true | KSA_OUTLINE_SKIP | | restart | outline_skip | Selection outline skip | The outline around selected parts is drawn only while a part is selected: a higher frame rate, the same image. Off: try it when a selected part has no outline.
crew_portraits | choice:always=Every frame/shown=When shown/shown_15=When shown, 15 a second | shown | KSA_CREW_PORTRAITS | | live | crew_portraits | Crew portraits | The crew panel's portraits are small views the game draws every frame while the vessel has crew, even with the panel closed. When shown draws them only while the panel is open: the same image. 15 a second: also at most that often, so the faces move less smoothly. Every frame is the game's own.
worker_parking | bool | true | KSA_WORKER_PARKING | | restart | worker_park | Worker parking | The game's idle background workers rest while they wait for work instead of keeping the CPU busy: the same frames, about a core and a half less CPU time. Off: try it when the game stutters.
fused_tessellation | bool | true | KSA_MTL_TESS_FUSE | tessellation | restart | | Fused tessellation | Terrain and ocean take less work for the GPU to tessellate: a higher frame rate over terrain, the same image. Off: try it when terrain or ocean look wrong.
vsync_pacing | bool | true | KSA_MTL_PRESENT_PACING | game:vsync | restart | | V-Sync pacing | With V-Sync, a frame starts as soon as the GPU is ready for it, not only when the display has shown the one before: a higher frame rate in a window. Off: try it when the frame rate is uneven with V-Sync.
background_compiling | bool | true | KSA_MTL_ASYNC_PIPELINES | | restart | | Background shader compiling | Shaders are compiled in the background, so the game doesn't stop for each one. Off: the game waits for each one; try it when something appears late or not at all.
shader_cache | bool | true | KSA_MTL_CACHE | | restart | | Shader cache | Translated shaders are kept on disk, in ~/Library/Caches/ksa-metal, so later starts don't translate them again. Off: every start translates them; try it when something is drawn wrong.
texture_mapping | bool | true | KSA_KTX_SHIM | | restart | | Texture file mapping | Textures' pixels are read from files instead of held in memory of their own, so macOS can let go of them when memory runs short and read them back later: about 3 GB less memory with the solar system. Off: try it when a texture looks wrong.
constant_memory | bool | true | KSA_MTL_AB_CONSTANT | | restart | | Constant-memory resources | Shaders read the textures and data they draw with through a faster kind of memory: a little faster, the same image. Off: try it when something is missing or drawn wrong.
uniform_references | bool | true | KSA_MTL_UNIFORM_REFS | | restart | | Uniform struct references | Shaders read the game's parameters in place instead of copying them over and over: the smoke of a big explosion draws about 7-9 % faster, with the same image. Off: try it when something looks wrong.

[game_features] Game features
tessellation | available | true | KSA_MTL_TESSELLATION | | restart | | Tessellation | Lets the game tessellate terrain and ocean; its own Terrain Tessellation setting still decides. Off: the game draws them without it.
ray_queries | available | true | KSA_MTL_RAYQUERY | | restart | | Ray queries | Lets the game place ground clutter with ray queries, and use ray tracing. Off: the game places clutter without them.
