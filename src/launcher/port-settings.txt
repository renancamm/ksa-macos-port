# The port settings: every setting of port-settings.toml, in the file's order. Three parts read this table: the
# launcher (launcher.sh), which exports each setting the file changes as the environment variable that KSA Metal, its
# shims and its hooks read; scripts/make-port-settings.sh, which writes the file's commented template from it; and the
# Mac Port tab in the game's settings (src/hooks/), which draws its rows from it. A variable already set when the game
# starts wins over the file.
#
# [<section>] <title>: starts a section of the file and of the tab; [developer]'s settings are in the file only.
# Then one setting per line:
#
#   key | type | default | variable | needs | applies | hook | label | help
#
#   type      bool: on or off; available: Available or Off, a feature the Mac offers the game, which the game's own
#             settings still turn on and off; choice:<value>=<label>/...; scale:<min>:<max>, a fraction shown in
#             percent; int:<min>:<max>; number:<min>:<max>; text
#   default   the value a line left out takes, and the one the variable means when it isn't set
#   variable  what the setting sets when it isn't at its default: on is 1 and off 0 (VAR=<value>: that, for on), other
#             types their value. Without one, the setting is the tab's own
#   needs     the settings it depends on (comma separated): <key> (on, or not empty), <key>=<value>, <key>!=<value>,
#             game:vsync or game:plume_trail_shadows (the game's own settings, which only the tab checks). While one
#             isn't met, it keeps its default
#   applies   live: on Apply, in the running game; restart: when the game starts
#   hook      the hook that does it (src/hooks/): the tab shows the setting as unavailable when the hook was skipped
#   label     its row in the tab; help: the row's tooltip and the file's comment

[image] Image
upscaling | choice:off=Off/metalfx=MetalFX/spatial=MetalFX spatial | off | KSA_UPSCALER | | restart | | Upscaling | Apple's MetalFX upscaler, for the settings below. MetalFX uses the last frames and is the sharpest; MetalFX spatial works one frame at a time. Off: the game draws as it does on other systems, and the settings below are off.
render_scale | scale:0.5:1 | 1.0 | KSA_RENDER_SCALE | upscaling!=off | restart | render_scale | Render scale | The 3D view's size, as a share of the window's. Below 100% the view is drawn smaller and MetalFX scales it back up: less work for the GPU, a slightly softer image.
frame_interpolation | bool | false | KSA_MTL_FX_INTERPOLATE | upscaling=metalfx | restart | render_scale | Frame interpolation | A frame made by MetalFX between every two the game draws: smoother motion, a little more delay. Works best when the game runs at least at half the display's refresh rate. Rocket plumes can look ragged in the frames MetalFX makes.
retina | bool | false | KSA_MTL_RETINA | upscaling!=off | restart | | Retina | The image at the display's full resolution: the game draws at the window's size, and MetalFX scales it up.

[performance] Performance
cloud_shadows | choice:normal=Normal/slow=Slow | normal | KSA_CLOUD_SHADOWS | | restart | cloud_shadows | Cloud shadows | Slow saves about 1.5 ms per frame over Earth; cloud shadows then follow moving clouds about 4 times more slowly. Normal is the game's own.
plume_shadows | choice:normal=Normal/light=Light | normal | KSA_PLUME_SHADOWS | game:plume_trail_shadows | restart | plume_shadows | Plume shadows | With the game's Plume trail shadows, the smoke's shadows are drawn from the sun into maps of their own. Light makes them smaller (4 of 128 pixels out to 3 km, instead of 8 of 512 out to 20 km): the smoke of a big rocket draws about 10-20% faster, and its shadows on the ground are coarser and end 3 km away. Normal is the game's own.
crew_portraits | choice:always=Every frame/shown=When shown/shown_15=When shown, 15 a second | shown | KSA_CREW_PORTRAITS | | live | crew_portraits | Crew portraits | The faces in the crew panel are views of their own, which the game draws every frame while the vessel has crew. When shown: only while the panel is on screen, which keeps their last image; 15 a second: also at most that often.

[optimizations] Optimizations
terrain_cache | bool | true | KSA_TERRAIN_CACHE | | restart | terrain_cache | Terrain cache | The terrain's height passes run only when their inputs changed, and every 2 s; its normals pass only when the planet has rotated. The same image.
outline_skip | bool | true | KSA_OUTLINE_SKIP | | restart | outline_skip | Selection outline skip | The outline pass around selected parts runs only while a part is selected. The same image.
worker_parking | bool | true | KSA_WORKER_PARKING | | restart | worker_park | Worker parking | The game's idle job workers sleep after 0.25 ms instead of spinning for half a frame: the same frames, with about 1.6 cores less CPU time.
fused_tessellation | bool | true | KSA_MTL_TESS_FUSE | tessellation | restart | | Fused tessellation | Terrain and ocean are tessellated without a trip through memory between the stages. Off: slower; try it when terrain or ocean look wrong.
vsync_pacing | bool | true | KSA_MTL_PRESENT_PACING | game:vsync | restart | | V-Sync pacing | With V-Sync, a frame starts when the GPU needs it, not only when the display shows the one before: in a window, frames that take less than about 23 ms on the GPU run faster.
background_compiling | bool | true | KSA_MTL_ASYNC_PIPELINES | | restart | | Background shader compiling | Shaders are compiled on worker threads, so the game doesn't wait for each one. Off: on the game's thread, when the game creates them.
shader_cache | bool | true | KSA_MTL_CACHE | | restart | | Shader cache | Translated shaders are kept on disk, in ~/Library/Caches/ksa-metal, so later starts don't compile them again.
texture_mapping | bool | true | KSA_KTX_SHIM | | restart | | Texture file mapping | Textures' pixels are mapped from files instead of kept in memory of their own, so macOS can page them out: about 3 GB less memory with the solar system.
constant_memory | bool | true | KSA_MTL_AB_CONSTANT | | restart | | Constant-memory resources | Shaders read their resources from constant memory, which is a little faster. Off: try it when a shader fails to compile.
uniform_references | bool | true | KSA_MTL_UNIFORM_REFS | | restart | | Uniform struct references | Shaders read the game's parameter blocks in place instead of copying them for each helper function: the smoke of a big explosion draws 6-9 % faster, with the same image. Off: try it when a shader looks wrong.

[game_features] Game features
tessellation | available | true | KSA_MTL_TESSELLATION | | restart | | Tessellation | Lets the game tessellate terrain and ocean; its own Terrain Tessellation setting still decides. Off: the game draws them without it.
ray_queries | available | true | KSA_MTL_RAYQUERY | | restart | | Ray queries | Lets the game place ground clutter with ray queries, and use ray tracing. Off: the game places clutter without them.
ray_tracing | available | true | KSA_MTL_RTPIPELINE | ray_queries | restart | | Ray tracing | Lets the game use ray tracing in the cockpit (IVA); its own IVA Ray Tracing setting still decides. Off: unavailable to the game.

[overlay] Overlay
performance_overlay | bool | false | MTL_HUD_ENABLED | | restart | | Performance overlay | Apple's Metal Performance HUD in a corner of the window: frame rate, frame and GPU times, and memory.

[benchmark] Benchmark
benchmark_mode | choice:fast=Fast, 1 minute/full=Full tour, 8 minutes | fast | | | live | | Benchmark | Fast: three places on Earth, the game paused, then a rocket's launch and explosion. The full tour flies from Earth to Jupiter, with a kitten in the grass, a launch and a 2,000-part rocket.
benchmark_restart | bool | false | | | live | | Restart the game first | Off: the benchmark plays in this game, and your game comes back when it ends. On: the game starts again for it, with a new game and none of your mods, the way benchmark.sh in the port folder runs it; when it ends, the game quits and the report's folder opens.
