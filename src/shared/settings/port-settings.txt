# The port settings: every setting of port-settings.toml, in the file's order. The hooks' loader
# (src/game/hooks/loader/) reads this table when the game starts and sets each setting the file changes as the
# environment variable that KSA Metal, its shims and its hooks read; the Mac Port tab in the game's settings
# (src/game/hooks/tab/) draws its rows from it; KsaPort.Tools.SettingsGenerator (README.md in this folder) makes the
# file's commented template from it, and port-settings.h, the variables and defaults the native code reads. A
# setting's variable is KSA_MTL_ and its key in capitals (shader_constant_memory: KSA_MTL_SHADER_CONSTANT_MEMORY);
# one already set when the game starts wins over the file.
#
# [<section>] <title> | <caption>: starts a section of the file and of the tab, the caption being the line under its
# title (and the file's comment); a section whose header ends in "| file" is in the file only, not in the tab. Then one
# setting per line; a choice can be followed by indented lines "<value> | <help>", what its values mean (their
# tooltips):
#
#   key | type | default | needs | applies | by | presets | memory | tag | label | help
#
#   type      bool: on or off; choice:<value>=<label>/...; scale:<min>:<max>, a fraction shown in percent;
#             int:<min>:<max>; number:<min>:<max>; numbers:<min>:<max>, that many numbers, comma separated, or none; text
#   default   the value a line left out takes, and the one the variable means when it isn't set or holds none of the
#             setting's values. The variable is set only when the setting isn't at its default: on is 1 and off 0,
#             other types their value
#   needs     the settings it depends on (comma separated): <key> (on, or not empty), <key>=<value>, <key>!=<value>,
#             game:vsync, game:plume_trail_shadows or game:pcss (the game's own settings, which only the tab checks).
#             While one isn't met, it keeps its default
#   applies   live: on Apply, in the running game (the hooks read it while the game runs); restart: when the game
#             starts
#   by        what does it (comma separated): driver (KSA Metal), ktx-shim, launcher (the app's executable, which
#             reads it from the file itself), hooks (the hooks and their loader),
#             hooks:<hook>, a class marked [Hook] (src/game/hooks/Hooks.cs) by its name, which the tab shows the
#             setting as unavailable without (skipped or failed), metal:<variable>, Apple's variable that Metal reads,
#             which the setting sets instead of its own, or tab: the tab's own, which sets no variable
#   presets   its values in the Mac Port tab's presets Performance, Balanced and Quality, comma separated (Game
#             Defaults gives it its default); none for a setting the presets leave alone. Every Extra Performance row
#             is on in Performance
#   memory    its values with Auto Memory Saving on, for a Mac with 8 GB of memory or less, 16 GB or less, and more,
#             comma separated; Off gives the row its default, the last tier's. None for a setting Auto Memory Saving
#             leaves alone (AutoMemorySaving.cs in this folder). A row has presets or memory values, never both
#   tag       a word the tab shows after the row's label: trade-off, on a Memory row with a cost a player can see
#   label     its row in the tab; help: the row's tooltip and the file's comment, which the values' help follows

[presets] Presets | The game's graphics and this tab, set together.
preset | choice:performance=Performance/balanced=Balanced/quality=Quality/game_defaults=Game Defaults | game_defaults | | live | tab | | | | Preset | The preset card picked last. Its name gets a * when settings differ from it.
auto_memory_saving | bool | true | | live | tab | | | | Auto Memory Saving | Sets the Memory rows for this Mac's memory. With 8 GB or less, it also lowers texture and shadow sizes.

[upscaling] Upscaling | A smaller 3D view, scaled up to the display.
upscaling | choice:off=Off/metalfx=Temporal/spatial=Spatial | off | | restart | hooks:RenderScale | spatial,metalfx,off | | | MetalFX | Draws the 3D view at the Render Scale and scales it up with Apple's MetalFX.
    off | The game's own: the 3D view is drawn at the window's size.
    metalfx | Builds each image from the ones before it: the sharpest, and it smooths edges. Fast motion can look a little soft.
    spatial | Scales each image on its own: no trails in motion, but softer below 100 %.
render_scale | scale:0.5:2 | 1.0 | upscaling!=off | restart | hooks:RenderScale | 0.5,0.75,1.0 | | | Render Scale | The 3D view's size before MetalFX scales it up. Lower is faster and softer. Above 100 % is sharper on Retina displays, and much slower.
skip_game_anti_aliasing | bool | true | upscaling=metalfx | restart | hooks:RenderScale | true,true,true | | | Skip Game Anti-Aliasing | Turns off the game's Anti-Aliasing (Display) with MetalFX Temporal, which smooths edges itself.

[performance] Extra Performance | Faster, with small trade-offs.
fewer_cloud_steps | bool | false | | restart | hooks:CloudSteps | true,true,false | | | Fewer Cloud Steps | Draws nearby clouds in fewer, longer steps. Faster with clouds in view.
fewer_smoke_steps | bool | false | | restart | hooks:SmokeSteps | true,true,false | | | Fewer Smoke Steps | Draws rocket smoke in fewer, longer steps. Faster in big plumes and explosions; a launch's plume looks a little different up close.
simpler_dense_smoke | bool | false | | restart | hooks:DenseSmoke | true,false,false | | | Simpler Dense Smoke | Draws dense rocket smoke in less detail. Faster there, a little softer from afar.
fewer_cloud_shadow_updates | bool | false | | restart | hooks:CloudShadows | true,true,false | | | Fewer Cloud Shadow Updates | Updates the shadows of clouds on the ground less often. A little faster; the shadows lag behind moving clouds.
lighter_warp_cloud_shadows | bool | false | | restart | hooks:WarpCloudShadows | true,true,false | | | Lighter Warp Cloud Shadows | At very high time warp, cloud shadows aren't rebuilt every frame, so warp keeps its speed. They fall out of place, then catch up.
lighter_plume_shadows | bool | false | game:plume_trail_shadows | restart | hooks:PlumeShadows | true,true,false | | | Lighter Plume Shadows | With Plume trail shadows (Graphics), rocket smoke casts coarser shadows, only within 3 km. A big rocket's smoke draws about 10-20 % faster.
simpler_pcss_shadows | bool | false | game:pcss | restart | hooks:ShadowSearch | true,true,true | | | Simpler PCSS Shadows | With Cascaded Shadow Filter on Pcss (Graphics), nearby soft shadows are simpler. Faster in grass; shadows cast from high above can look sharper.
baked_milky_way | bool | false | | restart | hooks:BakedMilkyWay | true,true,true | | | Baked Milky Way | Draws the Milky Way's dust from a picture made at start. Faster with much sky in view, and slightly softer.
crew_portraits_at_15_fps | bool | false | | live | hooks:CrewPortraits | true,false,false | | | Crew Portraits at 15 FPS | Draws the crew panel's portraits at 15 FPS. The faces move less smoothly.
lighter_tumbling_physics | bool | false | | restart | hooks:TumblingPhysics | true,true,false | | | Lighter Tumbling Physics | Tumbling pieces, such as falling boosters, take longer physics steps. Time warp slows down less while they fall.
debris_settles_in_warp | bool | false | | restart | hooks:DebrisSettle | true,true,false | | | Debris Settles in Warp | At time warp x8 and above, pieces nobody flies settle where they lie and pass through each other. Any inside the planet are removed.
steady_frame_rate | bool | false | game:vsync | restart | driver | true,false,false | | | Steady Frame Rate | With Vsync (Display), shows frames at an even half of the display's refresh rate. Steadier motion, less GPU work.

[experiments] Experiments | Features not finished, and values to measure with. | file
frame_interpolation | bool | false | upscaling=metalfx | restart | driver, hooks:RenderScale | | | | | A frame MetalFX interpolates between every two the game draws, shown before each one: smoother motion, about half a frame more delay, 1.7-3 ms more GPU a frame, so it pays only when the game already runs at half the refresh rate or more. While it is on, the game's UI pixel culling is off, so the scene is drawn under the HUD too (about 0.1 ms more GPU a frame): otherwise the interpolated frames smear the HUD, and probably the black boxes seen beside it came from there too. Known issue: ragged rocket plumes.
