# The port settings: every setting of port-settings.toml, in the file's order. The hooks' loader
# (src/game/hooks/loader/) reads this table when the game starts and sets each setting the file changes as the
# environment variable that KSA Metal, its shims and its hooks read; the Mac Port tab in the game's settings
# (src/game/hooks/tab/) draws its rows from it; KsaPort.Tools.SettingsGenerator (README.md in this folder) makes the
# file's commented template from it, and port-settings.h, the variables and defaults the native code reads. A
# setting's variable is KSA_MTL_ and its key in capitals (fused_tessellation: KSA_MTL_FUSED_TESSELLATION); one already
# set when the game starts wins over the file.
#
# [<section>] <title> | <caption>: starts a section of the file and of the tab, the caption being the line under its
# title (and the file's comment); a section whose header ends in "| file" is in the file only, not in the tab. Then one
# setting per line; a choice can be followed by indented lines "<value> | <help>", what its values mean (their
# tooltips):
#
#   key | type | default | needs | applies | by | presets | label | help
#
#   type      bool: on or off; choice:<value>=<label>/...; scale:<min>:<max>, a fraction shown in percent;
#             int:<min>:<max>; number:<min>:<max>; numbers:<min>:<max>, that many numbers, comma separated, or none; text
#   default   the value a line left out takes, and the one the variable means when it isn't set or holds none of the
#             setting's values. The variable is set only when the setting isn't at its default: on is 1 and off 0,
#             other types their value
#   needs     the settings it depends on (comma separated): <key> (on, or not empty), <key>=<value>, <key>!=<value>,
#             game:vsync, game:plume_trail_shadows or game:pcss (the game's own settings, which only the tab checks).
#             While one isn't met, it keeps its default
#   applies   live: on Apply, in the running game (the hooks read it while the game runs); restart: when the game
#             starts
#   by        what does it (comma separated): driver (KSA Metal), ktx-shim, hooks (the hooks and their loader),
#             hooks:<hook>, a class marked [Hook] (src/game/hooks/Hooks.cs) by its name, which the tab shows the
#             setting as unavailable without (skipped or failed), metal:<variable>, Apple's variable that Metal reads,
#             which the setting sets instead of its own, or tab: the tab's own, which sets no variable
#   presets   its values in the Mac Port tab's presets Performance, Balanced and Quality, comma separated (Game
#             Defaults gives it its default); none for a setting the presets leave alone. Every Extra Performance row
#             is on in Performance
#   label     its row in the tab; help: the row's tooltip and the file's comment, which the values' help follows

[image] Image | How the 3D view is drawn and scaled to the display.
upscaling | choice:off=Off/metalfx=Temporal/spatial=Spatial | off | | restart | hooks:RenderScale | spatial,metalfx,off | MetalFX | Draws the 3D view at the Render Scale below and scales it up to the display with Apple's MetalFX.
    off | The game's own. The 3D view is drawn at the window's size and stretched to the display.
    metalfx | Builds each image from the ones before it: the sharpest, even at a low Render Scale, and it smooths edges itself. Things that move fast can look a little soft.
    spatial | Scales each image on its own: nothing trails behind in motion, but the image is softer below 100 %. The game's Anti-Aliasing (Display) applies.
render_scale | scale:0.5:2 | 1.0 | upscaling!=off | restart | hooks:RenderScale | 0.5,0.75,1.0 | Render Scale | The size the 3D view is drawn at, as a share of the window's, before MetalFX scales it up. Lower is faster and a little softer. Above 100 % is sharper and much more work for the GPU, and changes nothing without a Retina display.
skip_game_anti_aliasing | bool | true | upscaling=metalfx | restart | hooks:RenderScale | true,true,true | Skip Game Anti-Aliasing | While MetalFX is on, the game's Anti-Aliasing (Display) is turned off: MetalFX smooths edges itself, so the game's would only cost frame rate and leave dark specks on the planet. Off: the game's setting applies, except CMAA2, which can't work with MetalFX.

[performance] Extra Performance | Faster, with a small change. Off is the game's own.
fewer_cloud_shadow_updates | bool | false | | restart | hooks:CloudShadows | true,true,false | Fewer Cloud Shadow Updates | The shadows that clouds cast on the ground are updated about 4 times less often: a little faster over Earth, and the shadows lag behind moving clouds. Off is the game's own.
lighter_warp_cloud_shadows | bool | false | | restart | hooks:WarpCloudShadows | true,true,false | Lighter Warp Cloud Shadows | At very high time warp, cloud shadows are no longer worked out whole every frame: the frame rate holds and warp keeps its speed. During warp they fall out of place, on vessels too, and catch up seconds after. Off is the game's own.
lighter_plume_shadows | bool | false | game:plume_trail_shadows | restart | hooks:PlumeShadows | true,true,false | Lighter Plume Shadows | With the game's Plume trail shadows (Graphics), the shadows rocket smoke casts from the sun have less detail and reach only within 3 km: a big rocket's smoke draws about 10-20 % faster, with coarser shadows on the ground. Off is the game's own.
simpler_pcss_shadows | bool | false | game:pcss | restart | hooks:ShadowSearch | true,true,true | Simpler PCSS Shadows | With the game's Cascaded Shadow Filter on Pcss (Graphics), soft shadows close to the camera look a shorter way for what casts them: about 9 % faster in grass. A shadow cast from high above can get a sharper edge. Off is the game's own.
baked_milky_way | bool | false | | restart | hooks:MilkyWayBake | true,true,true | Baked Milky Way | The Milky Way's dust clouds are drawn from a picture made once when the game starts: faster with much sky in view, and Milky Way Quality (Graphics) up to High costs no more than Low. Their finest grain is softer. Off is the game's own.
crew_portraits_at_15_fps | bool | false | | live | hooks:CrewPortraits | true,false,false | Crew Portraits at 15 FPS | The crew panel's portraits are drawn at most 15 times a second: the faces move less smoothly. Off: as often as the game draws them.
lighter_tumbling_physics | bool | false | | restart | hooks:TumblingPhysics | true,true,false | Lighter Tumbling Physics | Pieces tumbling through the air, such as boosters falling back after staging, take longer physics steps, and nothing spins faster than about 30 turns a second: time warp slows down less while they fall. Off is the game's own.
debris_settles_in_warp | bool | false | | restart | hooks:DebrisSettle | true,true,false | Debris Settles in Warp | At time warp of x8 or more, pieces nobody flies come to rest where they lie, at x64 seconds after they touch the ground, stay there, also in saves, and pass through each other. A piece that falls inside the planet is removed. Off is the game's own.

[optimizations] Optimizations | The same image, faster. Leave them on; turn one off to find a problem.
terrain_cache | bool | true | | restart | hooks:TerrainCache | | Terrain Cache | The terrain's shape and shading are worked out again only when something about them changed, instead of every frame: a higher frame rate, the same image. Off: try it when terrain looks wrong.
skip_unused_outlines | bool | true | | restart | hooks:OutlineSkip | | Skip Unused Outlines | The outline around selected parts is drawn only while a part is selected: a higher frame rate, the same image. Off: try it when a selected part has no outline.
skip_unused_overlays | bool | true | | restart | hooks:OverlaySkip | | Skip Unused Overlays | The steps that draw gizmos and orbit lines over the 3D view run only on frames that have some: a higher frame rate, the same image. Off: try it when a gizmo or an orbit line is missing.
skip_hidden_vessel_parts | bool | true | | restart | hooks:HiddenPartsSkip | | Skip Hidden Vessel Parts | Parts of a vessel hidden behind something else are no longer shaded: a higher frame rate, most in the cockpit, the same image. Off: try it when a vessel looks wrong.
skip_unused_ocean_blending | bool | true | | restart | hooks:OceanBlending | | Skip Unused Ocean Blending | Near the ocean's surface (below 9 km), the ocean is drawn without a step only views from higher up need: a higher frame rate, the same image. Off: try it when the ocean looks wrong.
clear_faded_smoke | bool | true | | restart | hooks:FadedSmoke | | Clear Faded Smoke | Smoke trails that have faded from view are removed. The game keeps some, from rockets with widely spaced boosters, for hours of game time, which slows it to a few frames a second after time warp. Off is the game's own.
skip_hidden_crew_portraits | bool | true | | live | hooks:CrewPortraits | | Skip Hidden Crew Portraits | The crew panel's portraits are small views the game draws every frame while the vessel has crew. They are drawn only while the panel is open: a higher frame rate, the same image. Off is the game's own.
skip_shadows_on_unlit_sides | bool | true | | restart | driver | | Skip Shadows on Unlit Sides | Shadows are worked out only where light reaches (terrain, vessels, kittens, grass, buildings, the sea, godrays, cockpit ray tracing): the cockpit draws about 45 % faster, grass at night about 8-16 %, with the same image. Off: try it when a shadow looks wrong.
fused_tessellation | bool | true | tessellation | restart | driver | | Fused Tessellation | Terrain and ocean are tessellated in one combined step, without a round trip through memory: a higher frame rate over terrain, the same image. Off: try it when terrain or ocean look wrong.
skip_gpu_texture_compression | bool | true | | restart | driver | | Skip GPU Texture Compression | Textures such as terrain heights, cloud noise and sea waves skip the GPU's compression, which slows drawing: terrain draws about 2-4 % faster, over clouds and the sea up to 10 %, with the same image and memory. Off: try it when something looks wrong.
iva_ray_search | bool | true | ray_tracing | restart | driver | | IVA Ray Search | With IVA Ray Tracing (Graphics) on, the cockpit's rays find what they hit through a faster kind of ray search: the cockpit draws about 6 % faster, with the same image. Off: try it when the cockpit looks wrong.
vsync_pacing | bool | true | game:vsync | restart | driver | | Vsync Pacing | With Vsync, a frame starts as soon as the GPU is ready for it, not only once the display has shown the one before: a higher frame rate in a window. Off: try it when the frame rate is uneven with Vsync.
background_shader_compiling | bool | true | | restart | driver | | Background Shader Compiling | Shaders are compiled in the background, so the game doesn't stop for each one. Off: the game waits for each one; try it when something appears late or not at all.
shader_cache | bool | true | | restart | driver | | Shader Cache | Translated shaders are kept on disk, in ~/Library/Caches/ksa-metal, so later starts don't translate them again. Off: every start translates them; try it when something is drawn wrong.
shader_constant_memory | bool | true | | restart | driver | | Shader Constant Memory | Shaders read the textures and data they draw with through a faster kind of memory: a little faster, the same image. Off: try it when something is missing or drawn wrong.
in_place_shader_parameters | bool | true | | restart | driver | | In-Place Shader Parameters | Shaders read the game's parameters where they are instead of copying them over and over: the smoke of a big explosion draws about 7-9 % faster, with the same image. Off: try it when something looks wrong.
compact_ray_tracing_memory | bool | true | ray_queries | restart | driver | | Compact Ray Tracing Memory | What places grass and traces the cockpit's rays sits in the memory the game set aside for it, instead of memory of its own: about 0.4 GB less memory with the solar system, the same image. Off: try it when grass or the cockpit look wrong.
unload_far_terrain | bool | true | | restart | hooks:FarTerrain | | Unload Far Terrain | The terrain of far worlds is let go and made again before the camera gets near: about 0.9 GB less memory with the solar system, the same image. Switching to a vessel at another world can pause a moment. Off: try it when terrain looks wrong.
texture_file_mapping | bool | true | | restart | ktx-shim | | Texture File Mapping | Textures' pixels are read from files instead of held in memory, so macOS can let go of them when memory runs short and read them back later: about 3 GB less memory with the solar system. Off: try it when a texture looks wrong.
idle_thread_sleep | bool | true | | restart | hooks:WorkerPark | | Idle Thread Sleep | The game's background threads sleep while they wait for work instead of keeping the CPU busy: the same frames, about a core and a half less CPU time. Off: try it when the game stutters.
loading_screen_fps_cap | bool | true | | restart | hooks:LoadingPace | | Loading Screen FPS Cap | While the game loads, its loading screen is drawn at most 30 times a second instead of after every step: the game loads about 2 seconds faster. Off: try it when the loading screen looks stuck.

[game_features] GPU Features | What the game may use on this Mac. Its own settings still decide.
tessellation | bool | true | | restart | driver | | Tessellation | Lets the game tessellate terrain and ocean; its own Tessellation setting (Graphics, Terrain) still decides. Off: the game draws them without it.
ray_queries | bool | true | | restart | driver | | Ray Queries | Lets the game place ground clutter with ray queries, and use ray tracing. Off: the game places clutter without them.
ray_tracing | bool | true | ray_queries | restart | driver | | Ray Tracing | Lets the game use ray tracing in the cockpit (IVA); its own IVA Ray Tracing setting (Graphics) still decides. Off: unavailable to the game.
hdr_output | bool | true | | restart | driver | | HDR Output | Lets the game show HDR on a display that has it; its own HDR (Experimental) setting (Display) still decides. [experiments] Experiments | Features not finished, and values to measure with. | file
frame_interpolation | bool | false | upscaling=metalfx | restart | driver, hooks:RenderScale | | | A frame MetalFX interpolates between every two the game draws, shown before each one: smoother motion, about half a frame more delay, 1.7-3 ms more GPU a frame, so it pays only when the game already runs at half the refresh rate or more. While it is on, the game's UI pixel culling is off, so the scene is drawn under the HUD too (about 0.1 ms more GPU a frame): otherwise the interpolated frames smear the HUD, and probably the black boxes seen beside it came from there too. Known issue: ragged rocket plumes.
