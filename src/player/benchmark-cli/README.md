# The benchmark's command

The program `./benchmark.sh` runs on the port folder's .NET runtime: it starts the game for a run, watches it, and
writes the report, its page and the zip; it also compares runs. [The benchmark's README](../../game/benchmark/README.md)
describes the benchmark, its options and these files ("How it works"); [`tests/`](tests/) holds its tests, which need no
game.
